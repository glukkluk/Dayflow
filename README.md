# OnTime

OnTime — вебзастосунок для планування особистого часу, роботи та навчання. Він поєднує календар подій і список завдань, допомагає стежити за дедлайнами та знаходити час для справ у щоденному розкладі.

## Можливості

- **Календар подій.** Перегляд розкладу на день, тиждень або місяць, а також у вигляді списку. Події можна переносити перетягуванням, створювати на весь день або налаштовувати щоденне, щотижневе чи щомісячне повторення. Якщо час подій перетинається, програма попереджає про конфлікт.
- **Завдання.** Для справ можна задавати дедлайн, пріоритет, категорію та орієнтовну тривалість, змінювати статус і відмічати виконання. Пошук і фільтри допомагають швидко знаходити потрібні та прострочені завдання.
- **Автоматичне планування.** Програма підбирає вільні проміжки з урахуванням робочих годин, наявних подій, дедлайнів і перерв між справами. Перед додаванням завдань у календар можна переглянути запропонований план.
- **Справи на вільний час.** Укажіть, скільки часу маєте, — OnTime запропонує відповідні за тривалістю завдання без дедлайну. Вибрану справу можна одразу взяти в роботу та додати до розкладу.
- **Нагадування.** Сповіщення всередині застосунку нагадують про початок подій і наближення дедлайнів. Їх можна переглянути в окремому розділі повідомлень.
- **Огляд дня й тижня.** На головній сторінці зібрано сьогоднішні події, найближчі дедлайни, прогрес виконання завдань і розподіл запланованого часу за категоріями.
- **Особисті налаштування.** У профілі можна вибрати часовий пояс, формат дати й часу, робочі години та тривалість перерв, а також додати аватар. Кольорові категорії допомагають розділяти роботу, навчання, відпочинок та інші справи.

Для роботи потрібен обліковий запис: доступні реєстрація за ім’ям користувача й email та вхід через Google за наявності налаштованої інтеграції. Інтерфейс пристосований до комп’ютерів і телефонів та підтримує світлу й темну теми.

## Як запустити

Потрібні **Python 3.14+**, **PostgreSQL 16+** та [uv](https://docs.astral.sh/uv/getting-started/installation/). Застосунок використовує Django 6.1. Усі команди виконуйте з кореня проєкту.

### 1. Встановіть залежності

```sh
uv sync
```

### 2. Створіть базу даних

У PostgreSQL від імені адміністратора виконайте, замінивши `your-password` власним паролем:

```sql
CREATE USER ontime WITH PASSWORD 'your-password';
CREATE DATABASE ontime OWNER ontime;
```

### 3. Налаштуйте оточення

Скопіюйте `.env.example` у `.env`:

```sh
cp .env.example .env
```

Заповніть у `.env`:

```dotenv
SECRET_KEY=вставте_згенерований_ключ
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
DB_NAME=ontime
DB_USER=ontime
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5432
```

Згенеруйте значення для `SECRET_KEY`:

```sh
uv run python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Для локального запуску поля `SUPABASE_*` та `GOOGLE_OAUTH2_*` можна залишити порожніми. Ключі Google потрібні лише для входу через Google.

### 4. Застосуйте міграції та запустіть сервер

```sh
uv run python app/manage.py migrate
uv run python app/manage.py runserver
```

Відкрийте <http://127.0.0.1:8000/> і зареєструйте обліковий запис.

За потреби створіть адміністратора для входу на <http://127.0.0.1:8000/admin/>:

```sh
uv run python app/manage.py createsuperuser
```
